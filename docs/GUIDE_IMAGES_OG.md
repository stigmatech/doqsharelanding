# 📸 Guide de Création des Images Open Graph

## 🎯 Spécifications Techniques

### Dimensions
- **Largeur :** 1200px
- **Hauteur :** 630px
- **Ratio :** 1.91:1
- **Format :** JPG (qualité 85-90%)
- **Taille cible :** 200-500KB par image

### Design Guidelines
- **Couleur principale :** Bleu DoQshare (#2563eb ou #1e40af)
- **Police :** Cohérente avec le site (DM Sans ou similaire)
- **Style :** Moderne, professionnel, cohérent avec la marque
- **Badge :** "doqshare.com" en haut à droite (optionnel)

## 🛠️ Méthodes de Création

### Option 1 : Screenshot + Retouche (Recommandé)

#### Outils pour Screenshot :
1. **Browser DevTools** (Chrome/Firefox)
   - Ouvrir la page
   - F12 → Cmd+Shift+P (Mac) ou Ctrl+Shift+P (Windows)
   - Taper "Capture full size screenshot"
   - Dimensions : 1200x630px (utiliser un viewport personnalisé)

2. **Extensions Browser :**
   - **Full Page Screen Capture** (Chrome)
   - **Fireshot** (Firefox/Chrome)
   - **Awesome Screenshot**

3. **Outils Mac :**
   - **CleanShot X** (payant, excellent)
   - **Skitch** (gratuit)
   - **Screenshot** (built-in avec Cmd+Shift+4)

4. **Outils Windows :**
   - **Snipping Tool** (built-in)
   - **Greenshot** (gratuit)
   - **ShareX** (gratuit, open-source)

#### Étapes :
1. Ouvrir la page en production : `https://doqshare.com/[lang]/[page]`
2. Ajuster le viewport à 1200x630px (DevTools → Toggle device toolbar)
3. Capturer la section hero/titre principal
4. Retoucher avec Photoshop/Figma/Canva pour :
   - Ajouter le logo DoQshare si nécessaire
   - Ajuster les couleurs
   - Ajouter un badge "doqshare.com"
   - Optimiser la taille (200-500KB)

---

### Option 2 : Design Tool (Figma/Canva/Photoshop)

#### Template Figma :
1. Créer un frame 1200x630px
2. Ajouter un fond dégradé bleu (#2563eb avec opacité)
3. Ajouter le titre, sous-titre, description
4. Ajouter le logo DoQshare
5. Exporter en JPG (qualité 85-90%)

#### Template Canva :
1. Créer un design 1200x630px
2. Utiliser un template "Social Media Post"
3. Personnaliser avec les couleurs DoQshare
4. Exporter en JPG

---

### Option 3 : Service en ligne

1. **htmlcsstoimage.com**
   - Créer un HTML avec le contenu
   - Convertir en image 1200x630px
   - Télécharger

2. **og-image.vercel.app**
   - Service Vercel pour générer des OG images
   - API simple à utiliser

## ✅ Checklist de Vérification

Pour chaque image créée :

- [ ] Dimensions : 1200x630px exactement
- [ ] Format : JPG
- [ ] Taille : < 500KB (idéalement 200-300KB)
- [ ] Qualité : Lisible et professionnelle
- [ ] Cohérence : Style similaire aux autres images OG
- [ ] Nom du fichier : Correct (ex: `og-case-studies.jpg`)
- [ ] Emplacement : `/public/images/`

---

## 🚀 Après Création

1. **Placer les images** dans `/public/images/`
2. **Vérifier** que les métadonnées référencent correctement les images
3. **Tester** avec :
   - [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)
   - [Twitter Card Validator](https://cards-dev.twitter.com/validator)
   - [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/)
