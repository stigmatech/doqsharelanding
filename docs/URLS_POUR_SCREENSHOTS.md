## 🛠️ Comment Capturer avec Chrome DevTools

1. **Ouvrir la page** dans Chrome
2. **Appuyer sur F12** (ou Cmd+Option+I sur Mac)
3. **Appuyer sur Cmd+Shift+P** (Mac) ou **Ctrl+Shift+P** (Windows)
4. **Taper "device"** et sélectionner "Toggle device toolbar"
5. **Ajuster les dimensions** à 1200x630px
6. **Appuyer sur Cmd+Shift+P** à nouveau
7. **Taper "screenshot"** et sélectionner "Capture full size screenshot"
8. **L'image sera téléchargée** automatiquement

---

## 📐 Alternative : Viewport Personnalisé

Si vous préférez capturer manuellement :

1. **Ouvrir DevTools** (F12)
2. **Toggle device toolbar** (Cmd+Shift+M)
3. **Cliquer sur "Edit"** à côté des dimensions
4. **Ajouter un device personnalisé :**
   - Name: "OG Image"
   - Width: 1200
   - Height: 630
5. **Sélectionner ce device**
6. **Capturer** avec votre outil de screenshot préféré

---

## 💡 Astuce : Utiliser un Service de Screenshot

Si vous préférez utiliser un service en ligne :

1. **htmlcsstoimage.com**
   - Coller le HTML (voir GUIDE_IMAGES_OG.md)
   - Générer l'image
   - Télécharger

2. **screenshotapi.net**
   - Entrer l'URL
   - Dimensions : 1200x630
   - Télécharger

## ✅ Après Capture

1. **Renommer** le fichier selon le nom indiqué (ex: `og-case-studies.jpg`)
2. **Placer** dans `/public/images/`
3. **Vérifier** la taille (< 500KB)
4. **Optimiser** si nécessaire avec TinyPNG ou ImageOptim
